# Task Manager — Structura proiectului

1. **Care este rolul folderului `src`?**
Folderul cu codul sursă al aplicației (componente, stiluri, punctul de intrare); tot ce scrii aici trece prin build-ul Vite.

2. **Ce reprezintă fișierul `App.jsx`?**
Componenta React principală (rădăcină), care compune celelalte componente și e randată în pagină.

3. **Ce informații sunt păstrate în `package.json`?**
Numele/versiunea proiectului, scripturile (`dev`, `build`...) și lista dependențelor (ex. `react`, `vite`).

4. **Ce reprezintă folderul `node_modules`?**
Folderul cu toate librăriile instalate (generat automat de `npm install`).
